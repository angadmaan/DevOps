## 📖 About

This directory contains my complete learning journey for the **AWS Certified Cloud Practitioner (CLF-C02)** certification using **AWS Skill Builder** and additional hands-on practice.

Instead of simply watching videos, I'm documenting everything I learn so that I can revise concepts quickly, reinforce my understanding, and track my progress over time.

My goal isn't just to pass the certification—it's to build a solid understanding of cloud computing that will support my journey toward **Cloud Security and DevOps**.

---

## 🎯 Objectives

- Understand cloud computing fundamentals
- Learn core AWS services
- Build hands-on experience with AWS
- Develop strong cloud concepts before moving to advanced topics
- Prepare for future AWS certifications
- Create reusable notes for interview preparation
