# 📖 Overview

This module explains the essential components that make computer networks function. It introduces the client-server communication model, peer-to-peer networks, common networking devices, and the different methods Internet Service Providers (ISPs) use to connect users to the internet. Understanding these concepts is fundamental for anyone interested in networking, cybersecurity, cloud computing, or DevOps, as every digital service relies on network communication.

---

# 🖥️ Clients and Servers

Most modern networks operate using the **client-server model**.

### Client

A **client** is a device or application that requests information or services from another computer.

Examples include:

- Desktop Computers
- Laptops
- Smartphones
- Tablets
- Web Browsers
- Email Applications

Clients initiate communication whenever they request a webpage, send an email, or access cloud services.

### Server

A **server** is a computer or software application that provides services or resources to clients.

Examples include:

- Web Servers
- File Servers
- Email Servers
- Database Servers
- DNS Servers

Servers receive client requests, process them, and return the requested information.

---

# 🤝 Peer-to-Peer (P2P) Networks

Unlike client-server networks, **Peer-to-Peer (P2P)** networks allow devices to communicate directly without a dedicated server.

Each computer acts as both a client and a server.

### Advantages

- Easy to configure
- Low cost
- No dedicated server required
- Suitable for small networks

### Disadvantages

- Limited scalability
- Lower security
- Difficult centralized management
- Reduced reliability

P2P networks are commonly used for home networks and simple file-sharing environments.

# 🔌 Network Components

Every network consists of different hardware devices that work together.

### End Devices

These are devices that send and receive data.

Examples include:

- Computers
- Smartphones
- Printers
- Servers
- IP Phones
- Smart TVs

### Intermediate Devices

These devices connect end devices and manage network traffic.

Examples include:

- Routers
- Switches
- Firewalls
- Wireless Access Points (WAPs)

They ensure that information reaches the correct destination efficiently and securely.

---

# 🌐 Common Networking Devices

### Router

A router connects multiple networks and forwards data between them.

Functions include:

- Internet connectivity
- Packet forwarding
- Traffic routing
- Connecting LANs to WANs

---

### Switch

A switch connects devices within the same Local Area Network (LAN).

Functions include:

- Connecting computers
- Improving communication efficiency
- Reducing unnecessary traffic

---

### Wireless Access Point (WAP)

A Wireless Access Point allows wireless devices to connect to a wired network using Wi-Fi.

It enables:

- Wireless internet access
- Mobile device connectivity
- Extended network coverage

---

### Firewall

A firewall protects a network by monitoring and filtering incoming and outgoing traffic.

It helps:

- Prevent unauthorized access
- Block malicious traffic
- Enforce security policies

Firewalls are one of the most important security components in modern networks.

---

# 🌍 ISP Connectivity Options

An **Internet Service Provider (ISP)** supplies internet connectivity to homes and businesses.

Common connection methods include:

### DSL (Digital Subscriber Line)

Uses telephone lines for internet access.

**Advantages**

- Affordable
- Widely available

**Disadvantages**

- Speed decreases with distance

---

### Cable Internet

Uses television cable infrastructure.

**Advantages**

- Faster than DSL
- Good availability

**Disadvantages**

- Shared bandwidth among users

---

### Fiber Optic Internet

Uses light transmitted through fiber-optic cables.

**Advantages**

- Very high speed
- Low latency
- Reliable connection

**Disadvantages**

- Higher installation cost
- Limited availability in some areas

---

### Satellite Internet

Provides connectivity through satellites.

**Advantages**

- Works in remote locations

**Disadvantages**

- Higher latency
- Weather can affect performance

---

### Cellular Networks

Provides internet using mobile communication towers.

Examples:

- 4G
- 5G

These networks offer internet connectivity for smartphones and mobile devices almost anywhere with cellular coverage.

---

# 📊 Key Takeaways

- Networks rely on clients and servers to exchange information.
- Peer-to-Peer networks allow devices to communicate directly.
- Routers connect different networks, while switches connect devices within the same network.
- Wireless Access Points provide Wi-Fi connectivity.
- Firewalls help protect networks from unauthorized access.
- ISPs connect homes and businesses to the global internet using DSL, Cable, Fiber, Satellite, or Cellular technologies.
- Understanding networking devices is essential for building a strong foundation in networking and cybersecurity.
