# 🏠 Home Network Basics

A **home network** is a group of interconnected devices that communicate with each other and share an internet connection. It allows users to access online services, transfer files, and connect multiple devices simultaneously.

Typical devices found in a home network include:

- Desktop Computers
- Laptops
- Smartphones
- Tablets
- Smart TVs
- Gaming Consoles
- Smart Home Devices
- Printers
- IP Cameras

Most home networks are managed using a wireless router, which acts as the central communication device.

---

# 🌐 Network Technologies in the Home

Home networks use both **wired** and **wireless** technologies.

### Wired Networks (Ethernet)

Ethernet uses physical cables to connect devices.

**Advantages**

- Faster speeds
- Stable connection
- Lower latency
- Better security

### Wireless Networks (Wi-Fi)

Wi-Fi connects devices using radio waves.

**Advantages**

- Mobility
- Easy installation
- Supports multiple devices
- No cables required

Many homes use a combination of Ethernet and Wi-Fi to balance speed and convenience.

---

# 📡 Wireless Standards

Wireless communication follows the IEEE **802.11** standards.

Common standards include:

- **802.11n (Wi-Fi 4)** – Improved speed and coverage.
- **802.11ac (Wi-Fi 5)** – Faster performance with better support for multiple devices.
- **802.11ax (Wi-Fi 6)** – Higher efficiency, improved performance, and lower latency in crowded environments.

Each new generation provides faster speeds, greater reliability, and better support for modern smart devices.

# ⚙️ Setting Up a Home Router

A home router connects the local network to the Internet through the ISP.

Basic configuration steps include:

1. Connect the router to the modem.
2. Access the router's administration page.
3. Change the default administrator username and password.
4. Configure the Wi-Fi network name (SSID).
5. Set a strong wireless password using WPA2 or WPA3 encryption.
6. Connect devices and verify internet connectivity.

Proper router configuration improves both network performance and security.

---

# 🔐 Best Practices for Home Network Security

A secure home network helps protect personal information and connected devices.

Recommended practices include:

- Change default login credentials.
- Use WPA2 or WPA3 encryption.
- Create strong passwords.
- Keep router firmware updated.
- Disable unused services.
- Use a guest network for visitors.
- Regularly monitor connected devices.

Following these practices reduces the risk of unauthorized access and cyberattacks.
